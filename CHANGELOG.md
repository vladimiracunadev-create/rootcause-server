# Changelog

All notable changes will be documented here. The project follows Semantic
Versioning once the public API reaches its first stable release.

## [0.1.0] - 2026-08-25

### Added

- Rust workspace with shared domain model, central server and native agent.
- Windows, Linux and macOS collection baseline.
- Embedded web console with dashboard and physical-style topology.
- SQLite persistence for assets, telemetry, incidents and audit events.
- Deterministic resource anomaly detection and evidence-backed incidents.
- API token protection, safe bind defaults and guided-response boundary.
- Cross-platform CI, packaging templates and security requirements.
